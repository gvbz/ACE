# ACEmulator Core Server

ACEmulator is an open-source C# server for Asheron's Call. It uses MySQL or
MariaDB. This repository also contains the shared Unreal client source.

- [AC:Unreal desktop](Unreal/README.md)
- [AC:VR for PC VR and Quest](Quest/README.md)
- [AC:Mobile for Android](Mobile/README.md)

Fork the repository and submit a pull request. Follow the
